# Stepik to Markdown

Скрипт/расширение для экспорта любого урока со Stepik в формат Markdown (`.md`).
Копируется весь урок со всеми шагами. Комментарии не подтягиваются. Снизу справа появляются две кнопки для копирования в буфер обмена и для загрузки.

Смысл:
Если скачать сайт и попробовать скормить его LLM-модели, например для обучения, то вскоре придётся столкнуться с закончившимися лимитами. Скачанный MHTML содержит тонны мусора, скриптов, ненужных данных и т.д., которые высасывают все токены. Скрипт всё это вычищает оставляя чистый markdown, идеально понятный нейроночкам.

С помощью данного скрипта мне удалось уменьшить размер файла и количество потраченных токенов **примерно в 40—60 раз**.

## Способ 1: Расширение для браузера (Chrome, Edge, Brave)

Не требует установки сторонних менеджеров скриптов.

1. Скачайте архив с расширением из раздела **[Releases](../../releases/latest)** и распакуйте его в любую папку (или скачайте папку `extension/` из этого репозитория).
2. Откройте страницу расширений в вашем браузере:
   * Chrome: `chrome://extensions/`
   * Edge: `edge://extensions/`
3. Включите тумблер **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с файлами расширения (`manifest.json` и `content.js`).
5. Откройте или обновите (`F5`) любую страницу урока на Stepik. Посмотрите на нижний правый угол.


## Способ 2: Скрипт для Tampermonkey / Violentmonkey (подходит также для Firefox и Safari)

1. Установите расширение **Tampermonkey** или **Violentmonkey** для вашего браузера.
   * *Для браузеров на базе Chromium (Chrome, Edge, Яндекс) обязательно включите **«Режим разработчика»** на странице расширений браузера, иначе менеджер скриптов не сможет запускаться на страницах.*
2. Откройте файл [`userscript/stepik-to-md.user.js`](userscript/stepik-to-md.user.js) в этом репозитории и нажмите кнопку **Raw** (или скопируйте его содержимое и вставьте в новый скрипт в панели Tampermonkey, нажав `Ctrl + S`).
3. Обновите (`F5`) страницу урока на Stepik.

## Как пользоваться

На странице любого урока Stepik (`https://stepik.org/lesson/...`) в правом нижнем углу появится компактная панель:

* **📋 Копировать MD (`Alt + C`)** — собирает все шаги текущего урока и копирует готовый Markdown сразу в буфер обмена.
* **💾 .md** — скачивает урок на компьютер в виде `.md`-файла.
